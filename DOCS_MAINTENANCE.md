# Регламент актуальности витрины МФМ

Публичная документация описывает текущее состояние продукта, а не историю отдельных исследовательских этапов.

## Источники статуса

Перед изменением статуса функции используются в таком порядке:

1. фактическое поведение актуального приложения;
2. актуальный `CHANGELOG.md` приложения;
3. актуальный `PILOT_ACCESS_WORKFLOW.md`;
4. публичная документация витрины.

Старый отчёт `SERVER-AUTH NO_GO` может доказывать состояние своего этапа, но не отменяет более поздний подтверждённый запуск ограниченного пилота.

## Обязательная проверка изменения

1. Сверить `README.md`, `ARCHITECTURE.md`, `EDITIONS_AND_STATUS.md`, `access.html`, `status.html` и `docs/settings.html`.
2. Проверить, что заявка, создание учётки, изоляция данных и границы нереализованных функций описаны одинаково.
3. Выполнить `npm run docs:check`.
4. Запустить статический сервер и выполнить `npm run docs:check -- --base-url=http://127.0.0.1:ПОРТ`.
5. Проверить все страницы в браузере на ширине 390 и 320 px: HTTP 200, отсутствие горизонтального выхода и ошибок консоли.
6. Убедиться, что в публикацию не попали исходный код приложения, секреты, выгрузки `localStorage` и пользовательские данные.
7. После публикации повторно проверить живой адрес GitHub Pages.

Если источники статуса противоречат друг другу, публикация останавливается до явного решения владельца.

## Движение и доступность

- Финансовые числа могут оживать только после появления в области просмотра; итоговый текст обязан в точности совпадать с исходным HTML.
- Числа внутри одного смыслового блока запускаются каскадом, чтобы движение не превращалось в одновременное мелькание.
- Полосы и графики раскрываются без изменения размеров макета и не могут создавать горизонтальный выход.
- Подсветка содержания показывает текущий раздел и остаётся понятной без наведения мышью.
- При `prefers-reduced-motion: reduce` счётчики сразу показывают итоговые значения, графики остаются полностью видимыми, циклическое движение отключается.
- Движение не является единственным способом передать смысл: подписи, числа, линии и доступные названия сохраняются в статическом HTML.
